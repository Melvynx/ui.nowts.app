## About

The **Better Auth Sign In With** component provides OAuth authentication buttons with built-in loading states, error handling, and toast notifications. It supports GitHub and Google providers out of the box.

### Features

- ✅ **OAuth providers**: GitHub and Google support
- ✅ **Loading states**: Automatic loading indicators during sign-in
- ✅ **Error handling**: Toast notifications for errors
- ✅ **Success feedback**: Toast notifications for successful sign-ins
- ✅ **Responsive design**: Works well on all screen sizes
- ✅ **Theme-aware icons**: Uses SVGL images with automatic theme switching
- ✅ **TypeScript support**: Fully typed for better developer experience

## API

### SignInWith

```tsx
type SignInWith = {
  type: "github" | "google";
  className?: string;
  buttonProps: ComponentProps<typeof LoadingButton>;
  onSignIn: (provider: "github" | "google") => Promise<void>;
}
```

| Property | Type | Description | Required |
|----------|------|-------------|----------|
| `type` | `"github" \| "google"` | OAuth provider type | ✅ |
| `onSignIn` | `(provider) => Promise<void>` | Sign-in handler function | ✅ |
| `buttonProps` | `ComponentProps<typeof LoadingButton>` | Props for the underlying button | ✅ |
| `className` | `string` | Additional CSS classes | - |

### Button Props

The component accepts all props supported by the `LoadingButton` component, including:

- `size`: Button size (`sm`, `default`, `lg`)
- `variant`: Button variant (`default`, `destructive`, `outline`, `secondary`, `ghost`, `link`)
- `disabled`: Disable the button
- And all standard HTML button attributes

### With redirect handling

<CodeBlock contentClassName="h-fit" fileName="components/AuthButtons.tsx">

```tsx
import { SignInWith } from "@/components/better-auth-sign-in-with";
import { signIn } from "@/lib/auth-client";
import { useRouter, useSearchParams } from "next/navigation";

export function AuthButtons() {
  const router = useRouter();
  const searchParams = useSearchParams();
  const callbackUrl = searchParams.get("callbackUrl") || "/dashboard";

  const handleSignIn = async (provider: "github" | "google") => {
    const result = await signIn[provider]({
      callbackURL: callbackUrl,
    });
    
    if (result.success) {
      router.push(callbackUrl);
    }
  };

  return (
    <div className="grid grid-cols-2 gap-3">
      <SignInWith
        type="github"
        onSignIn={handleSignIn}
        buttonProps={{}}
      />
      <SignInWith
        type="google"
        onSignIn={handleSignIn}
        buttonProps={{}}
      />
    </div>
  );
}
```

## Troubleshooting

### Sign-in not working
- Ensure Better Auth is properly configured with your OAuth providers
- Check that provider credentials are set in your environment variables
- Verify the `onSignIn` function is properly implemented

### Loading states not showing
- Ensure React Query is properly set up in your app
- Check that the `onSignIn` function returns a Promise

### Toast notifications not appearing
- Ensure Sonner is installed and configured
- Check that the Sonner toaster is rendered in your app layout
