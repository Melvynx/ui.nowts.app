## About

The **Use Mobile** hook is a lightweight React hook that detects if the current device is mobile based on screen width using a responsive breakpoint.

### Features

- ✅ **Responsive detection**: Uses media queries to detect mobile devices
- ✅ **SSR-safe**: Returns `false` initially to prevent hydration mismatches
- ✅ **Real-time updates**: Automatically updates when window is resized
- ✅ **Customizable breakpoint**: Uses 768px breakpoint (standard mobile breakpoint)
- ✅ **Performance optimized**: Uses native `matchMedia` API
- ✅ **TypeScript support**: Fully typed with proper return types

### With custom breakpoint logic

```tsx
import { useIsMobile } from "@/hooks/use-mobile";
import { Dialog, DialogContent } from "@/components/ui/dialog";
import { Drawer, DrawerContent } from "@/components/ui/drawer";

export function AdaptiveModal({ open, onOpenChange, children }) {
  const isMobile = useIsMobile();
  
  if (isMobile) {
    return (
      <Drawer open={open} onOpenChange={onOpenChange}>
        <DrawerContent>
          {children}
        </DrawerContent>
      </Drawer>
    );
  }
  
  return (
    <Dialog open={open} onOpenChange={onOpenChange}>
      <DialogContent>
        {children}
      </DialogContent>
    </Dialog>
  );
}
```

## API

### useIsMobile

```tsx
function useIsMobile(): boolean
```

Returns `true` if the current viewport width is below 768px (mobile), `false` otherwise.

| Return | Type | Description |
|--------|------|-------------|
| `isMobile` | `boolean` | Whether the current device is mobile |

## Implementation Details

### Breakpoint

The hook uses a breakpoint of **768px** which is the standard mobile breakpoint used by most CSS frameworks including Tailwind CSS.

### SSR Compatibility

The hook returns `false` initially to prevent hydration mismatches between server and client. The actual mobile state is determined after the component mounts on the client.

### Performance

- Uses the native `matchMedia` API for optimal performance
- Event listener is properly cleaned up when component unmounts
- No polling or repeated calculations

## Troubleshooting

### Hook returns wrong value initially
This is expected behavior for SSR compatibility. The hook will return `false` initially and then update to the correct value after hydration.

### Not updating on window resize
Make sure you're using the hook in a client component. The hook won't work in server components.

### Different breakpoint needed
The current implementation uses 768px. To use a different breakpoint, you can modify the `MOBILE_BREAKPOINT` constant in the hook file.
