## About

The **SVGL Images** component provides a seamless way to display icons from the [SVGL](https://svgl.app/) library with automatic theme switching support using next-themes.

### Features

- ✅ **Automatic theme switching**: Displays different icons for light and dark themes
- ✅ **SVGL integration**: Access to hundreds of beautiful SVG icons
- ✅ **next-themes compatibility**: Works with any next-themes setup
- ✅ **Full img props support**: All standard HTML img attributes supported
- ✅ **TypeScript support**: Fully typed for better developer experience

## API

### SvglImg

```tsx
type SvglImgProps = {
  lightIconName: string;
  darkIconName: string;
} & Omit<ImgHTMLAttributes<HTMLImageElement>, "src" | "alt">;
```

| Property | Type | Description | Required |
|----------|------|-------------|----------|
| `lightIconName` | `string` | Icon name for light theme | ✅ |
| `darkIconName` | `string` | Icon name for dark theme | ✅ |
| `...imgProps` | `ImgHTMLAttributes` | All standard HTML img attributes | - |

### Finding Icon Names

Visit [SVGL.app](https://svgl.app/) to browse available icons. The icon name is the filename without the `.svg` extension.

Examples:
- `github_light` → `https://svgl.app/library/github_light.svg`
- `github_dark` → `https://svgl.app/library/github_dark.svg`
- `react` → `https://svgl.app/library/react.svg`

## Benefits

### Theme-aware icons
Automatically switches between light and dark variants based on the current theme, providing optimal contrast and visual consistency.

### Performance
Icons are loaded directly from SVGL's CDN, ensuring fast loading times and reducing bundle size.

### Accessibility
Automatically sets appropriate alt text based on the icon name for better screen reader support.

## Troubleshooting

### Icons not switching themes
- Ensure next-themes is properly configured in your app
- Check that both `lightIconName` and `darkIconName` are valid SVGL icon names

### Icons not loading
- Verify the icon names exist on [SVGL.app](https://svgl.app/)
- Check network connectivity to `svgl.app`
- Ensure icon names don't include the `.svg` extension
